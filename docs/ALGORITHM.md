## 2. 매수 신호

```
주간 판정 (금요일 미국 종가 기준)
  순매수율 = (이번 주 순매수 주식수) ÷ (직전 주 보유 주식수) × 100
  문턱     = 그 시점까지의 순매수율 확장창 90분위 (최소 52주, 1주 시프트)

  순매수율 ≥ 문턱  →  매수 신호
```

- **비율 기준**이다. 절대 주식 수로 하면 펀드 규모 변화에 문턱이 오염된다.
- 문턱은 **과거 데이터로만** 계산한다(룩어헤드 없음).
- 진입은 **신호 다음 거래일 종가** (아크 공시가 장 마감 후이므로).
  한국시간 기준 **화요일 새벽 5~6시**.

### 기술적 필터 (적용됨)

```
매수 신호 = (순매수율 ≥ 문턱)  AND  (전고점 252일 대비 낙폭 ≤ -30%)
```

**두 조건을 모두 만족해야 신호다.** 낙폭은 주가만으로 정해지므로 룩어헤드가 없다.

적용 효과 (신호 20건 → 15건):

| | 신호 | 전체평균 | 승률 | 최악 |
|---|---|---|---|---|
| 필터 없음 | 20 | +22.9% | 85% | **-28.3%** |
| **낙폭 ≤ -30%** | **15** | **+31.3%** | **93%** | **-3.5%** |

-20% ~ -45% 전 구간이 무필터보다 나았다(고원). 자세한 근거는 FINDINGS.md 참조.

## 3. 포지션

**신호마다 독립 포지션.** 신호가 뜰 때마다 새로 100 을 넣고, 각 포지션은
자기 진입일 기준으로 청산 조건을 본다. 이미 보유 중이어도 새로 진입한다.

`armed`(RSI 70 돌파 여부)도 포지션마다 따로 센다.

## 4. 매도 신호

```
포지션별로 판정
  진입 후 126거래일(약 6개월) 경과  →  매도
```

**지표도 아크도 쓰지 않는다. 경과일수만 본다.**

### 왜 RSI 를 뺐나

RSI 70 이탈 규칙은 '단일 포지션 복리' 틀에서 골랐다. 그 틀은 겹치는 신호를
하나로 병합해 매매가 5건뿐이었다. 이후 자본 모델을 **신호마다 독립 100** 으로
바꿨는데 매도 규칙을 다시 고르지 않았다. 틀이 바뀌자 순위가 뒤집혔다.

독립 포지션 틀(총 16건) 평가액:

| 규칙군 | 중앙값 | 최솟값 | 최댓값 |
|---|---|---|---|
| **고정 보유** | **2236** | 1875 | 2514 |
| RSI 이탈 + 6개월 상한 | 1978 | 1820 | 2311 |
| 트레일링 스톱 + 6개월 | 1795 | 1757 | 2282 |

| 보유 기간 | 평가 | 승률 | 최악 |
|---|---|---|---|
| 5개월 | 2226 | 94% | **-3.5%** |
| **6개월 (채택)** | **2290** | 88% | **-3.5%** |
| 7개월 | 2210 | 88% | -3.5% |
| 9개월 | 2464 | 88% | -37.0% |
| 10개월 | 2514 | 88% | **-61.2%** |
| **RSI 70 이탈** | **2093** | 94% | -3.5% |

더 오래 들면 평가액은 오르지만 최악 사례가 **-3.5% → -61.2%** 로 급격히 나빠진다.
5~7개월 구간이 최악 -3.5% 를 유지하면서 안정적이라 그 중앙인 6개월을 택했다.

### 아크 매도를 넣어봤으나 기여하지 않았다

| 규칙 | 평가 |
|---|---|
| 126일 고정 (아크·지표 없음) | **2290** |
| 아크 하위10% AND RSI≥70 | 2328 (+1.7%) |
| 아크 매도 단독 + 상한 | 1856 |

조합의 청산 15건 중 **10건이 상한 도달**이었다. 즉 아크 조건이 거의 걸리지 않아
사실상 '오래 들고 있던' 효과였지 아크가 정보를 준 것이 아니다.

## 5. 판정 흐름

```
전 구간 재생 → 현재 포지션 확정 (상태 파일에 의존하지 않는다)

  보유 없음  →  매수 신호 감시
  보유 있음  →  포지션별로 매도 조건 감시 + 새 매수 신호도 감시
```
