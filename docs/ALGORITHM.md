## 2. 매수 신호

```
주간 판정 (금요일 미국 종가 기준)
  순매수율 = (이번 주 순매수 주식수) ÷ (직전 주 보유 주식수) × 100
  문턱     = 그 시점까지의 순매수율 확장창 90분위 (최소 52주, 1주 시프트)

  순매수율 ≥ 문턱  →  매수 신호
```

- **비율 기준**이다. 절대 주식 수로 하면 펀드 규모 변화에 문턱이 오염된다.
- 문턱은 **과거 데이터로만** 계산한다(룩어헤드 없음).
- 진입은 **신호 다음 거래일 종가** (아크 공시가 장 마감 후이므로).
  한국시간 기준 **화요일 새벽 5~6시**.

### 기술적 필터 (적용됨)

```
매수 신호 = (순매수율 ≥ 문턱)  AND  (전고점 252일 대비 낙폭 ≤ -30%)
```

**두 조건을 모두 만족해야 신호다.** 낙폭은 주가만으로 정해지므로 룩어헤드가 없다.

적용 효과 (신호 20건 → 15건):

| | 신호 | 전체평균 | 승률 | 최악 |
|---|---|---|---|---|
| 필터 없음 | 20 | +22.9% | 85% | **-28.3%** |
| **낙폭 ≤ -30%** | **15** | **+31.3%** | **93%** | **-3.5%** |

-20% ~ -45% 전 구간이 무필터보다 나았다(고원). 자세한 근거는 FINDINGS.md 참조.

## 3. 포지션

**신호마다 독립 포지션.** 신호가 뜰 때마다 새로 100 을 넣고, 각 포지션은
자기 진입일 기준으로 청산 조건을 본다. 이미 보유 중이어도 새로 진입한다.

`armed`(RSI 70 돌파 여부)도 포지션마다 따로 센다.

## 4. 매도 신호

```
포지션별로 판정
  RSI(14) 가 70 을 넘은 적이 있고(armed), 다시 70 아래로 내려오면  →  매도
  진입 후 126거래일(약 6개월) 이 지나면                            →  매도
```

- **아크 매도는 따라가지 않는다.** 아크가 판 뒤 주가는 오히려 올랐다(상승 확률 86%).
- 매도 판정에 아크 데이터는 쓰지 않는다. 오직 RSI 와 경과일수.

## 5. 판정 흐름

```
전 구간 재생 → 현재 포지션 확정 (상태 파일에 의존하지 않는다)

  보유 없음  →  매수 신호 감시
  보유 있음  →  포지션별로 매도 조건 감시 + 새 매수 신호도 감시
```
