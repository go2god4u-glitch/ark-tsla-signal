## 한 줄 요약

> **매수는 아크, 매도는 RSI.** 낙폭이 -30% 이하일 때만 산다.
> 신호마다 독립 포지션, RSI 70 이탈 또는 6개월에 청산.

가장 중요한 한계 하나: **완료 매매 승률 100% 는 착시다.**
RSI 70 을 찍어야 청산되므로 손실 중인 포지션은 통계에 들어가지 않는다.
현재 1건이 -3.5% 로 열려 있다.
