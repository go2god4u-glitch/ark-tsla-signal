# ARK × TSLA — 아크가 사면 매수신호인가

ARK Invest(ARKK·ARKQ)의 테슬라 보유 변화를 매수신호로 삼았을 때 실제로 통하는지 검증한다.
결론부터: **사건 단위로 보면 통한다. 다만 완료된 사건이 7개뿐이라 확정할 수 없다.**

## 결과

사건 단위 비교 (6개월 보유, 무작위 진입 대비 초과수익)

| 신호 | 독립 사건 | 초과수익 | 승률 | p |
|---|---|---|---|---|
| **아크 매수신호** | **9** | **+37.6%** | **86%** | 0.011 |
| 낙폭 -50% 이하 (아크 무시) | 3 | +21.3% | 67% | 0.174 |
| 낙폭 -40% 이하 (아크 무시) | 4 | -11.1% | 50% | 0.680 |
| 낙폭 -30% 이하 (아크 무시) | 7 | -12.7% | 50% | 0.775 |

낙폭만으로는 방향성조차 남지 않는다. 사건 수를 확보하려고 임계를 넓히면 초과수익이 음수가 된다.
아크 신호는 사건 9개를 확보하면서 초과가 양수로 남는 유일한 쪽이다.

부수적으로 확인한 것:

- 신호는 **오른 뒤가 아니라 빠진 뒤에** 뜬다. 직전 1달 주가 평균 -7.8% (기준 +2.6%).
- **1달 늦게 사도** 초과 +21.6% (p=0.017)로 버틴다. 3달 늦으면 사라진다.
- "전고점"을 126일/252일/504일/사상최고 중 무엇으로 잡든 방향은 같다.

## 신호 규칙

> ARKK+ARKQ 합산 보유 주식 수의 **주간 증가분**이
> **그 시점까지의 데이터로 계산한 상위 10% 문턱**을 넘으면 신호.

- 문턱은 매주 다시 계산한다(확장창 분위수, 최소 52주, 1주 시프트).
- ARK 공시는 장 마감 후 → **금요일 판정, 월요일 종가 진입.**
- 5년간 19주에 신호, 이를 묶으면 **9개 사건**.

## 파이프라인

```bash
python -m venv .venv && .venv/bin/pip install -r requirements.txt

.venv/bin/python fetch_ark_monthly.py   # ARK 보유 이력 수집 (이어받기 지원)
.venv/bin/python clean_holdings.py      # 분할 보정 + 왕복 왜곡 제거
.venv/bin/python make_app_data.py       # 사건 단위 분석 -> data/app_data.json
```

`app.src.html` 의 `/*__DATA__*/null` 자리에 `data/app_data.json` 을 치환하면 `app.html` 이 된다.

| 파일 | 역할 |
|---|---|
| `fetch_ark_monthly.py` | arkfunds.io 수집. **월말일을 제외한** 월 단위 요청 |
| `clean_holdings.py` | 분할 보정, 왕복 스파이크 제거 → `data/holdings_clean.csv` |
| `make_app_data.py` | 사건 단위 백테스트 → `data/app_data.json` |
| `app.src.html` / `app.html` | 대시보드 (템플릿 / 데이터 인라인본) |
| `build_chart.py` | 보유량 추이 PNG (초기 산출물) |
| `dashboard.src.html` | 보유량 대시보드 (초기 산출물) |

## 데이터 함정 — [TROUBLESHOOTING.md](TROUBLESHOOTING.md)

이 저장소의 가치 절반은 아래 함정들에 있다. 자세한 내용은 별도 문서 참조.

1. **arkfunds.io 는 월말일에만 500을 반환한다.** 범위 요청에 월말이 끼면 청크 전체가 실패한다.
2. **펀드 파일 전체가 스케일링되는 왕복 왜곡이 있다.** 2025-08 ARKK 내재 AUM 이 7.3B→12.65B→7.1B.
3. **분할 보정을 날짜로 자르면 안 된다.** ARK 는 분할 당일에도 분할 전 주식 수를 보고했다.
4. **비중(%)은 타이밍 신호가 아니다.** 분모가 주가와 함께 움직인다.
5. **겹치는 관측을 독립으로 세면 안 된다.** 이걸 틀려서 한때 정반대 결론이 나왔다.

## 한계

- **종목 1개, 5년, 완료 사건 7개.** p=0.011 이지만 확정할 수 있는 것은 없다.
- 2023년 1월 건이 +127%로 평균을 끌어올린다. 빼면 6개 평균 +35%, 승률 83%.
- **생존한 종목을 뒤돌아본 것이다.** 이 기간 테슬라는 -72% 낙폭에서 회복했다.
  회복하지 못하는 종목에 같은 규칙을 쓰면 정반대가 된다.
- 최근 성적이 나쁘다. 2025-10 진입은 6개월 -24%.
- 수수료·슬리피지·세금 미반영.
